# - Focuses on simplicity — you don’t need HTML, CSS, or JavaScript.

# opencv-python-headless==4.10.0.84 :-
# What it is: A headless build of OpenCV (no GUI features like imshow, highgui, or video display windows).

# Key Uses:
# Image and video processing in server environments.
# Works well in cloud/production setups where GUI support isn’t available.
# Provides core OpenCV functionality (filters, transformations, object detection).

# Why headless:
# Saves space and dependencies (no need for Qt or GTK).
# Ideal for Streamlit, Flask, FastAPI, or other web apps where you don’t need to open native windows.
